### D. API UTILISÉES

| API | Méthode | Utilisation |
| --- | ------- | ----------- |
| `/api/stores` | GET | Liste des magasins (avec `isActive=true`) |
| `/api/stores` | POST | Création d'un magasin |
| `/api/stores/[id]` | PATCH | Modification d'un magasin |
| `/api/stores/[id]/activate` | POST | Activation d'un magasin |
| `/api/stores/[id]/deactivate` | POST | Désactivation d'un magasin |

**Payloads utilisés**:
- Création/Modification: `{ name, code, address, city, country, phone, email }`
- Activation/Désactivation: Aucun body requis
