## G. Seed

**Pourquoi les doublons ont été créés:**
Le seed utilise `prisma.store.create()` au lieu de `prisma.store.upsert()`. Chaque exécution du seed crée de nouveaux enregistrements sans vérifier s'ils existent déjà.

Même problème pour Customer: `prisma.customer.create()` au lieu de `upsert()`.

**Correction nécessaire:**
Remplacer `create()` par `upsert()` dans `prisma/seed.ts` pour:
- Store (avec where: { organizationId_code: { organizationId, code } })
- Customer (avec where: { organizationId_email: { organizationId, email } })

Cela rendra le seed idempotent: plusieurs exécutions ne créeront plus de doublons.
