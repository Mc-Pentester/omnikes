## D. POST /API/STORES

**État**: ✅ **IMPLEMENTÉ**

**Fichier**: `src/app/api/stores/route.ts`

**Flux**:
```
HTTP POST
   ↓
auth/session
   ↓
requireCurrentOrganizationId()
   ↓
validation du body (Zod storeSchema)
   ↓
vérification doublon code (storeRepository.findByCode)
   ↓
storeService.create(organizationId, data)
   ↓
StoreRepository.create()
   ↓
public.stores
```

**Payload attendu**:
```json
{
  "name": "string (obligatoire)",
  "code": "string (obligatoire)",
  "address": "string (optionnel)",
  "city": "string (optionnel)",
  "country": "string (optionnel)",
  "phone": "string (optionnel)",
  "email": "string (optionnel)",
  "isActive": "boolean (optionnel)"
}
```

**Réponse succès**:
```json
{
  "store": {
    "id": "...",
    "name": "...",
    "code": "...",
    "isActive": true
  }
}
```
HTTP Status: 201 Created

## F. AUTORISATION

**État**: ⚠️ **PARTIEL**

**Mécanisme actuel**: Authentification uniquement (`requireCurrentOrganizationId()`)

**État RBAC**: 
- Le système RBAC existe (Role, Permission, RolePermission)
- MAIS la permission `store.create` n'est pas définie
- MAIS l'API n'utilise pas `requirePermission()`

**Conséquence**: Tout utilisateur authentifié peut créer un magasin dans son organisation.

**Note**: L'ajout de `requirePermission('store.create')` est recommandé pour une étape future après l'implémentation du système d'initialisation des permissions.
