## 1. FLUX POS

### Fonction de chargement des magasins
**Fichier**: `src/app/pos/page.tsx` (lignes 152-188)

**Fonction**: `fetchStores()`

```typescript
const fetchStores = useCallback(async () => {
  if (!user) return;

  try {
    const response = await fetch('/api/stores?isActive=true');
    
    if (!response.ok) {
      throw new Error('Failed to fetch stores');
    }
    
    const data = await response.json();
    const fetchedStores = data.stores || [];
    setStores(fetchedStores);

    // Validate and restore current store from localStorage
    if (currentStoreId) {
      const isValidStore = fetchedStores.some((s: Store) => s.id === currentStoreId);
      if (!isValidStore) {
        clearCurrentStore();
      } else {
        const store = fetchedStores.find((s: Store) => s.id === currentStoreId);
        if (store) {
          setCurrentStore(store);
        }
      }
    } else if (fetchedStores.length === 1) {
      setCurrentStore(fetchedStores[0]);
    }
  } catch (err) {
    console.error('Error fetching stores:', err);
    setError('Impossible de charger les magasins');
    setStores([]);
  }
}, [user, currentStoreId, setCurrentStore, clearCurrentStore]);
```

## 4. STORE REPOSITORY

**Fichier**: `src/repositories/store.repository.ts`

### Méthode listByOrganization
```typescript
async listByOrganization(organizationId: string, options: {
  isActive?: boolean;
  skip?: number;
  take?: number;
} = {}) {
  const { isActive, skip = 0, take = 50 } = options;

  const where: Prisma.StoreWhereInput = {
    organizationId,
  };

  if (isActive !== undefined) {
    where.isActive = isActive;
  }

  const [stores, total] = await Promise.all([
    prisma.store.findMany({
      where,
      skip,
      take,
      orderBy: {
        name: 'asc',
      },
    }),
    prisma.store.count({ where }),
  ]);

  return {
    stores,
    total,
    skip,
    take,
  };
}
```

**Requête Prisma exacte**:
```prisma

  organizationId: string,
  isActive?: boolean  // si spécifié
}
```

**Observation**: 
- Si erreur API → `setError('Impossible de charger les magasins')` + `setStores([])`
- Si API retourne `[]` → `stores.length === 0` → "Aucun magasin disponible"

**Problème potentiel**: Les deux cas (erreur API vs absence de données) affichent le même message "Aucun magasin disponible" car `setStores([])` est appelé dans le catch.

## 10. ANALYSE DES CAUSES POSSIBLES

### CAS A: Aucun Store n'existe réellement dans la base
**Probabilité**: ⚠️ **ÉLEVÉE**
**Raison**: L'application est nouvelle, probablement pas de seed de données

### CAS B: Un Store existe mais isActive = false
**Probabilité**: ⚠️ **MOYENNE**
**Raison**: Le POS filtre avec `?isActive=true`

### CAS C: Un Store existe mais appartient à une autre Organization
**Probabilité**: ❌ **FAIBLE**
**Raison**: L'API utilise `requireCurrentOrganizationId()` qui filtre par organizationId de la session

### CAS D: Un Store existe et appartient à la bonne Organization, mais l'API ne le retourne pas
**Probabilité**: ❌ **TRÈS FAIBLE**
**Raison**: La requête Prisma est simple et correcte

### CAS E: L'API retourne correctement le Store, mais le frontend POS interprète mal la réponse
**Probabilité**: ❌ **FAIBLE**
**Raison**: Le mapping `data.stores || []` est correct

### CAS F: Le contrôle d'accès utilisateur masque le Store
**Probabilité**: ❌ **FAIBLE**
**Raison**: Pas de contrôle d'accès utilisateur au niveau store (seulement multi-tenancy par organization)

### CAS G: La session possède une mauvaise organisation ou aucun organizationId
**Probabilité**: ❌ **FAIBLE**
**Raison**: L'utilisateur peut se connecter, donc la session est valide

### CAS H: Erreur API / Prisma / authentification
**Probabilité**: ⚠️ **MOYENNE**
**Raison**: Possible erreur de connexion à la base de données
