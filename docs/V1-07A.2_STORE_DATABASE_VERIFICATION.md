## ROOT CAUSE

**ROOT CAUSE CONFIRMÉE**:
```
Les migrations Prisma n'ont pas été appliquées à la base de données PostgreSQL.
```

**Détails**:
- La base de données PostgreSQL existe et est accessible
- MAIS aucune table Prisma n'a été créée
- Le schéma Prisma dans `prisma/schema.prisma` définit les modèles
- MAIS ces modèles n'existent pas physiquement dans PostgreSQL
- Les tables suivantes n'existent pas:
  - `Organization`
  - `Store`
  - `User`
  - `Product`
  - `Sale`
  - `Payment`
  - `TaxConfiguration`
  - etc.

**Pourquoi**:
- L'application est nouvelle (v0.1.0)
- Aucune commande `npx prisma migrate deploy` ou `npx prisma db push` n'a été exécutée
- La base de données est vide de toute structure Prisma
