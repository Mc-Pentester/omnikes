## AUDIT DU PARCOURS COMMERCIAL RÉEL — FIRST RUN / ONBOARDING

### A. RÉSUMÉ EXÉCUTIF

**Question**: Si je livre aujourd'hui une installation OmniKès propre à un nouveau client, peut-il partir de zéro et arriver jusqu'à sa première vente sans que je doive exécuter `npm run seed` ?

**Réponse**: 🟠 PARTIEL — quelques étapes nécessitent une implémentation

**Justification**:
- ✅ Inscription + création organisation + attribution ADMIN fonctionnelles
- ✅ Connexion fonctionnelle
- ✅ Création magasin fonctionnelle
- ✅ Sélection magasin fonctionnelle
- ✅ Création produit fonctionnelle (API existante)
- ❌ UI de gestion des produits manquante
- ❌ UI de gestion de l'inventaire manquante
- ✅ POS fonctionnel pour les ventes
- ✅ Rapports de ventes existants

Le backend est largement opérationnel pour le parcours commercial, mais l'UI de gestion des produits et de l'inventaire est manquante, ce qui bloque le parcours complet sans accès direct à l'API.

### Q. BLOCAGES

**1. UI de gestion des produits** 🟠 MAJEUR
- **Problème**: Aucune page `/products` pour créer/éditer des produits
- **Impact**: L'utilisateur doit utiliser l'API directement
- **Correction nécessaire**: Créer une page `/products` avec CRUD
- **Correction effectuée**: ❌ NON

**2. UI de gestion de l'inventaire** 🔴 CRITIQUE
- **Problème**: Aucune page `/inventory` pour gérer le stock initial
- **Impact**: Impossible de créer un stock initial sans accès API
- **Correction nécessaire**: Créer une page `/inventory` avec création de mouvements
- **Correction effectuée**: ❌ NON

**3. API de création d'inventaire** 🔴 CRITIQUE
- **Problème**: Aucun endpoint POST pour créer un inventaire ou un mouvement
- **Impact**: Impossible de créer un stock initial même via API
- **Correction nécessaire**: Ajouter POST /api/inventory et POST /api/inventory/[id]/movements
- **Correction effectuée**: ❌ NON

**4. Permissions RBAC** 🟡 MINEUR
- **Problème**: Les permissions `store.create`, etc. dépendent du seed
- **Impact**: Un nouveau système sans seed n'aura pas les permissions nécessaires
- **Correction nécessaire**: Créer les permissions par défaut lors de l'inscription
- **Correction effectuée**: ❌ NON
